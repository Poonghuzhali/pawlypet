# Petify — Pet Care Home Page

Responsive React home page built from the Figma design (UI Practice).

## Stack

- React 19
- Vite
- Tailwind CSS
- JavaScript (JSX)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```

## Sections

- Header with navigation, search, and cart icons
- Hero — “Everything Your Pet Needs”
- Why Pet Parents Love Us (feature cards)
- Shop by Category (dogs, cats, small pets)
- Meet Our Experts
- Meet the Breeds
- Curated For Excellence (products)
- FAQ accordion
- Talk to a Vet CTA banner
- Contact & footer

Replace Unsplash placeholder images in `src/data/homeData.js` and components with your exported Figma assets when available.
